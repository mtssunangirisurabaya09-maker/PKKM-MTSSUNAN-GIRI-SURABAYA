# PKKM MTs SUNAN GIRI SURABAYA

Halaman profil tautan untuk mengakses dokumen, dokumentasi, dan media sosial
PKKM MTs Sunan Giri Surabaya.

## Menjalankan website

Pastikan Node.js sudah terpasang, lalu jalankan:

```sh
npm install
npm start
```

Buka `http://localhost:3000` di browser.

Tautan dokumen Google Drive dan media sosial dapat diperbarui langsung di
`public/index.html`.
